공수뚝딱 계정 삭제

공수뚝딱은 '사장님과 연결'을 켠 경우에만 계정이 만들어집니다. 혼자 기록만 하셨다면 계정이 없으며, 앱을 삭제하면 모든 데이터가 함께 사라집니다.

앱에서 직접 삭제하기 (권장)

  1. 공수뚝딱 앱을 엽니다
  2. 아래쪽 설정 탭 → 사장님과 연결 카드로 이동합니다
  3. 맨 아래 계정 삭제를 누릅니다
  4. 안내를 확인하고 두 번 확인하면 즉시 삭제됩니다

무엇이 지워지나요

서버에서 즉시 삭제되는 것
  • 카카오 로그인 계정 정보(회원번호·닉네임)
  • 내 소속 정보 — 사장님 화면의 팀원 목록에서 사라집니다
  • 내가 보낸 출결 신고 전부 — 사장님 화면에서도 사라집니다
지워지지 않는 것
  • 휴대전화 안에 저장된 내 공수·급여 기록 — 내 임금의 근거가 되는 기록이라 앱이 임의로 지우지 않습니다. 직접 지우시려면 앱을 삭제하거나 기기 설정에서 앱 데이터를 삭제하세요.
  • 이미 내보낸 급여명세서 PDF·백업 파일 — 기기나 보내신 곳에 남아 있습니다

계정 삭제는 되돌릴 수 없습니다. 사장님과 다시 일하시게 되면 초대코드로 새로 연결하셔야 합니다.

일부만 지우고 싶다면

  • 특정 날짜 기록만 — 달력에서 그 날짜를 눌러 기록을 지우면 서버에서도 즉시 삭제됩니다. 계정은 그대로 유지됩니다.
  • 연결만 끊기 — 설정 > 사장님과 연결 > 연결 끊기. 소속 정보는 지워지지만, 이미 보낸 출결 신고는 임금 지급 근거가 되는 근로 기록이라 사장님 팀 기록으로 남습니다. 이것까지 지우려면 계정 삭제를 이용하세요.

앱을 쓸 수 없는 경우

휴대전화를 분실했거나 앱을 이미 삭제하신 경우 loadguess@gmail.com 으로 카카오 닉네임과 소속 팀 이름을 알려주시면 본인 확인 후 처리해 드립니다. 접수 후 10일 이내에 삭제하고 회신드립니다.

보관 기간

삭제 요청이 처리되면 서버에서 지체 없이 삭제되며 별도로 보관하지 않습니다. 접속 기록은 서버 운영 목적으로 최대 3개월 보관 후 삭제됩니다.
